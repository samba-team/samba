Release Announcements
=====================

This is the first pre release of Samba 4.26.  This is *not*
intended for production environments and is designed for testing
purposes only.  Please report any defects via the Samba bug reporting
system at https://bugzilla.samba.org/.

Samba 4.26 will be the next version of the Samba suite.


UPGRADING
=========


NEW FEATURES/CHANGES
====================


Undocumented samba-tool dbcheck --yes changes
---------------------------------------------

The --yes option for samba-tool dbcheck, when combined with --fix,
tells samba-tool to fix everything it can without asking questions.

There has been an undocumented feature whereby if --yes was followed
by certain special strings it would assume yes to only some of the
questions. In addition, if --yes was followed by a less special string
(including DN strings that dbcheck ought to expect), the failure would
be quite mysterious. This aspect of --yes has been removed and
replaced by --yes-restricted-to-rule. The usual sense of --yes works
as expected.

The use of --yes with special strings was only intended for automated
tests, so was undocumented and unannounced. --yes-restricted-to-rule
is also not mentioned by --help or the man page, and the magic strings
it uses are not considered to be stable. We only mention this change
in case people have stumbled across and come to rely on the feature.
Otherwise please ignore this news.

Reporting bugs & Development Discussion
#######################################

Please discuss this release on the samba-technical mailing list or by
joining the #samba-technical:matrix.org matrix room, or
#samba-technical IRC channel on irc.libera.chat

If you do report problems then please try to send high quality
feedback. If you don't provide vital information to help us track down
the problem then you will probably be ignored.  All bug reports should
be filed under the Samba 4.1 and newer product in the project's Bugzilla
database (https://bugzilla.samba.org/).
